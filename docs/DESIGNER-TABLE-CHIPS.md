# Задание дизайнеру: стол и фишки PokChe

Нужны отдельные прозрачные ассеты для мобильного покерного тренажёра. Русский интерфейс, фон #f5faf7, тёмный текст #243e35, мятно-зелёные акценты. Карты и персонаж Иваныч уже готовы — их менять не нужно.

## 1. Стол — poker-table-v2.png
Сдержанный аккуратный покерный стол сверху, вытянутый горизонтальный овал, ширина примерно в 1,8 раза больше высоты. Тёмно-зелёное сукно, тонкий тёмный мягкий борт, умеренная светотень. Меньше мультяшной объёмности, без толстого контура. Без перспективного наклона, без окружения, надписей, логотипа, карт, игроков, кнопки дилера и фишек. Без встроенных стульев: места будут отдельными круглыми метками интерфейса, это позволит им оставаться читаемыми и не перекрывать стол.

PNG RGBA 1600×1000, прозрачный фон. Центр в (800,500), внешний контур стола в прямоугольнике x=80..1520, y=100..900; поверхность сукна x=160..1440, y=180..820. Не обрезать тени. Чистый центр: там будут пять общих карт и банк. Приложить превью на фоне приложения при ширине 300 px. Если создаёшь SVG, нужен настоящий вектор, а не PNG внутри SVG.

## 2. Фишки — отдельные PNG RGBA 512×512
Одинаковый слегка наклонённый вид сверху и единый масштаб самой фишки во всех файлах. Строгие, хорошо различимые на 24–48 px, без чисел и денежных символов (значения подписывает приложение). Цвета: бирюзовый, молочный, приглушённый золотой; можно маленький бордовый акцент.
- chip-single.png — одна фишка.
- chips-small.png — низкая стопка из 3 фишек.
- chips-medium.png — стопка из 7 фишек.
- chips-large.png — две аккуратные стопки, 7 и 10 фишек.
- chips-pot.png — небольшая группа из трёх стопок для банка, низкий широкий силуэт.

Центрировать объекты, оставить одинаковые прозрачные поля. Объекты без фона и без большой падающей тени. Приложить общий лист предпросмотра на мятном фоне в размерах 24, 36, 48 и 72 px. Это обозначения величины, не буквальный счёт денег по числу нарисованных фишек.

## 3. dealer-button.png
Отдельная небольшая молочная круглая кнопка с тонким золотистым краем и тёмной буквой D. Вид строго сверху, прозрачный фон, 256×256. Должна читаться при 18–24 px. Не объединять со столом.

Отдать исходники и отдельные экспорты, без создания единого спрайта. Никаких новых персонажей и перерисовки колоды не требуется.
