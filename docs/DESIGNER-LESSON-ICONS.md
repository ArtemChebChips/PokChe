# Задание дизайнеру: иконки уроков PokChe

Сделай через ImageGen девять отдельных иллюстраций для уроков 05–12 и дополнительного «Игра вдолгую». Они заменят временные векторные значки. Уроки 00–04 уже имеют удачные готовые картинки: их не перерисовывать. В результате у каждого из 14 материалов будет своя иллюстрация в едином стиле.

## Референсы — обязательно посмотреть перед генерацией

Возьми реальные изображения из `public/art/`: `topic-cards.png`, `topic-combinations.png`, `topic-actions.png`, `topic-positions.png`, `topic-starting-hands.png`. Они задают стиль, а не готовые композиции для повторения. Особенно полезны `topic-actions.png` и `topic-starting-hands.png`.

Стиль: небольшие объёмные рисованные предметы, как существующие карты и фишки. Чёткий тёмно-бирюзовый контур, мягкая иллюстративная светотень, кремовая бумага, мятный и глубокий бирюзовый, небольшие коралловые акценты. Аккуратный уютный рисунок без фотореализма, блестящего пластика и тяжёлого 3D. Не заменять картинку тонким линейным значком.

## Общий промпт для каждого изображения

Создай одну самостоятельную предметную иллюстрацию для маленькой иконки урока в приложении PokChe. Используй приложенные существующие иконки как стилевые референсы: тот же рисунок, контуры, палитру, мягкий объём и визуальную плотность. Один ясный силуэт, один главный предмет и не более двух вспомогательных. В центре квадратного холста, на настоящем прозрачном фоне. Предмет должен оставаться понятным при показе 48×48 px и различаться с другими иконками по силуэту. Никаких рамок, подложек, круглых бейджей, текста, названия урока, водяных знаков, внешнего свечения, длинных теней или фона с нарисованной шахматной прозрачностью. Допустимы только корректные печатные индексы и масти на картах. Иллюстрация декоративная, не скриншот интерфейса и не схема покерной задачи. Не копируй готовую пару тузов и стопки из референсов: нужен новый сюжет, указанный ниже.

К этому промпту для каждой генерации добавь соответствующий сюжет из таблицы.

## Экспорт и проверка

- Отдельный PNG RGBA 256×256 для каждого сюжета. Исходную генерацию высокого разрешения сохранить отдельно.
- Видимая композиция примерно 208–224 px по большей стороне; безопасные прозрачные поля не менее 16 px. Оптический центр и воспринимаемый размер выровнять с существующими иконками.
- Контуры и важные детали не обрезать. Внутренние мягкие тени допустимы, широкая тень вокруг предмета — нет.
- Проверить каждую при **48×48** и **36×36** на фоне приложения **#f5faf7**. Если сюжет превращается в пятно, упростить детали; не увеличивать число предметов.
- Приложить обзор всех 14 иконок: пять существующих и девять новых рядом, в реальном размере 48 px. Превью отдельно, не вместо отдельных PNG.
- Сложить результат в `design/lesson-icons-v2/`: девять файлов, `preview-48.png`, `preview-36.png`, `README.md`, исходники в `originals/`. В README перечислить размеры, прозрачность и смысл иконок.
- Код приложения и `public/` не менять: разработчик подключит готовый пакет. Существующие дизайнерские оригиналы не перезаписывать.

Дополнительные ассеты сейчас не требуются. Кнопка дилера уже выбрана пользователем: `dealer-button-relief.png`, с тонким объёмным бортиком; её заново генерировать не нужно.
