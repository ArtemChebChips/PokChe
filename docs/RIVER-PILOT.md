# Риверный пилот MVP · 19.09.2026

Это собственные синтетические конечные игры, а не импорт чужих чартов. Полноценный пилот b-inary/postflop-solver из исходного плана и большая база постфлопа ещё не выполнены. Для первой рабочей версии выбран меньший проверяемый объём: пять полярных игр ривера с одной ставкой.

## Условия

Два игрока, банк 100. Ставящий знает свой тип: сильная рука либо блеф. Защитник имеет один блеф-кетчер и не знает тип ставящего. Сильная рука всегда побеждает, блеф всегда проигрывает. Ставящий выбирает чек/ставку, защитник — пас/колл. Нет комиссии, рейзов, будущих карт; стеки позволяют выбранную ставку. Диапазон заведомо синтетический. В приложении он обозначен как модель, а не реальная стратегия.

Доска Qs 8h 3c 2d 9s. Примеры типов: As Ah / Jh 6h, у защитника Kc Kd. Их порядок независимо проверен pokersolver. Размеры 25/50/75/100/150, исходные доли сильных рук 50/50/40/60/50% соответственно. Нельзя произвольно заменять карты или частоты, сохраняя прежний ответ.

## Расчёт и независимые проверки

`scripts/solve-river-models.py` составляет матрицу выплат по четырём чистым планам ставящего и двум ответам защитника. SciPy 1.16.2, метод HiGHS, решает прямую и двойственную задачи линейного программирования. Повторные расчёты с допусками 1e-7 и 1e-9 совпали; разрыв лучших ответов меньше 1e-7 фишки. JSON хранит параметры, версию, SHA-256 скрипта, частоты и EV.

Результаты дополнительно сверяются аналитически:

- Частота колла защитника P/(P+B) делает блеф безразличным между ставкой и чеком.
- Доля блефов среди ставок B/(P+2B) делает блеф-кетчер безразличным между коллом и пасом.
- При доле сильных рук v и их ставке 100% частота ставки с блефом v/(1-v) × B/(P+B). Здесь во всех пяти случаях она внутри [0,1].
- Нельзя считать частоту действия его EV. В задачах с равным EV принимаются оба ответа.

Это свидетельство решения именно этой конечной игры. Оно не означает, что найдено равновесие полного холдема или подходящий размер реальной ставки.

## Воспроизведение

```powershell
python -m pip install --target .tools/solver-python -r scripts/solver-requirements.txt
python scripts/solve-river-models.py
npm test
```

Зависимости нужны только для повторного получения набора. Приложение использует маленький проверенный JSON и работает офлайн. `.tools/` исключён из Git. Не копировать сторонние реализации или данные в приложение.

Источники метода: [SciPy linprog/HiGHS](https://docs.scipy.org/doc/scipy/reference/optimize.linprog-highs.html), [исходный HiGHS](https://github.com/ERGO-Code/HiGHS). Статистические упражнения 11 используют [интервал Уилсона, NIST](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm); эталоны независимо получены `scipy.stats.binomtest(...).proportion_ci(method='wilson')`.
