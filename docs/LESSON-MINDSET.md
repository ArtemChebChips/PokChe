# Дополнительный урок «Игра вдолгую» — план до реализации

Цель: отделять качество решения от случайного результата, записывать конкретный вопрос и выбирать следующую тренировку. Восемь коротких страниц, без экзамена по психологии.

1. Результат не равен качеству: положительный EV допускает проигрыш отдельной раздачи.
2. Повторяемый пример: вероятность победы 60%, итог +10/−10, EV +2. Результат одного раза не обязан быть +2; шанс трёх проигрышей подряд 0,4³=6,4% при независимости.
3. Замечаем тильт: реакция на желание немедленно отыграться, совет Иваныча.
4. Ограничения выбираем заранее: время, отдельная сумма, без универсального числа безопасных бай-инов.
5. Запись раздачи: позиции, эффективный стек, банк, карты, размеры, один вопрос до раскрытия результата.
6. Повторяющееся заблуждение: различать ошибку в правилах, счёте и неподтверждённое предположение о сопернике.
7. Следующая тренировка: ошибка → семейство → новая похожая задача → разбор. Не механически повторять один ответ.
8. Памятка: условия → варианты → причина → пауза → разбор. Читать можно независимо от прогресса остальных уроков.

Проверка: 0,6×10−0,4×10=2; 0,4³=0,064. Весь материал доступен на 320/390 px; completion без обязательной практики; старое завершение mindset не сбрасывать.
