# Следующие шаги PokChe

Актуально: 19 сентября 2026, рабочая учебная MVP.

1. Пользователь просматривает уроки начиная с непроверенного 07 и практику. Исправлять конкретные замечания, сохраняя работающие главы, стол и масштабирование карт.
2. На физическом iPhone проверить установку, обновление, нижний отступ, офлайн и сохранение прогресса. Браузерная эмуляция уже проверена на 320/390.
3. Следующее содержательное расширение — стратегический префлоп 05Б/05В. Сначала принять данные: профиль, позиции, эффективный стек, размеры, рейк/анте, лицензия, версия и частоты. До этого не оценивать открытие конкретной руки как точный GTO-ответ. См. TRAINER-DATA-PLAN.md и SOURCES.md.
4. Для полноценной постфлоп-практики выполнить исходный пилот b-inary/postflop-solver с проверкой устойчивости и импортируемым деревом. Нынешние пять игр HiGHS — отдельный ограниченный набор, подробно описанный в RIVER-PILOT.md. Не считать их заменой всей стратегической базы.
5. Затем расширить реальные узлы: варианты блокеров, EV потерь, смешанные частоты, ветвящиеся раздачи. Новые размеры/карты требуют нового расчёта; похожесть картинки не достаточна.
6. Турниры, короткие стеки, пуш/фолд, ICM и выплаты — отдельная программа с собственными данными. Настройка предпочтения пока не переключает базовые ответы.

Перед каждым новым уроком: план → примеры → числовые эталоны → реализация. После законченной порции: подходящие тесты, мобильный просмотр, коммит/push, успешный Actions и фактический bundle. Разрешение пользователя на публикацию действует постоянно. Девять PNG иконок уже подключены. Экскурсия из восьми сцен готова; после появления Peugeot можно обновить её финальную сцену. Последний выбор кнопки D — объёмный dealer-button-relief.png, он уже подключён.

Ограничения намеренно простые: localStorage без синхронизации, незавершённая сессия при перезагрузке начинается заново, проверенные ответы сохраняются. Ключ river.progress.v1 не менять; design/ не трогать. Общий исходный план ROADMAP-07-12.md остаётся ориентиром следующих расширений, а не декларацией о выполнении каждой его стратегической части.
