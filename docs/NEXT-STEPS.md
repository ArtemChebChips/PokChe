# Следующие шаги PokChe

1. Пользователь смотрит исправленные уроки 01/02 и новый урок 03. После каждого законченного обновления делать коммит и push в main, проверять Actions и GitHub Pages: пользователь проверяет с телефона.
2. После замечаний к 03: исправить его и подготовить 04 «Стартовые руки», как договорились — текущий и следующий урок за запрос. Сначала структура, примеры и необходимость ассетов, потом реализация.
3. Не менять остальные уроки заранее. Для новых ассетов подготовить конкретное задание отдельному дизайнеру; текущей порции хватило готовых материалов.
4. Диапазоны с оценкой подключать только после проверки происхождения, формата, условий игры и прав на данные. Не выдумывать GTO, EV или частоты.
5. На реальном iPhone проверить установку, обновление без потери прогресса и офлайн. Браузерные проверки этого не заменяют.

Простой локальный проект для двух игроков: без сервера, аккаунтов, платежей и новой инфраструктуры. Прогресс сохраняем под прежним ключом river.progress.v1.
