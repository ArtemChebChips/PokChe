# Следующие шаги PokChe

1. Пользователь смотрит исправленные уроки 02/03, практику и новый урок 04. После каждого законченного обновления делать коммит и push в main, проверять Actions и GitHub Pages: пользователь проверяет с телефона.
2. После замечаний к 04: исправить его и определить структуру 05 «Решения на префлопе» без неподтверждённых чартов, как договорились — текущий и следующий урок за запрос. Сначала структура, примеры и необходимость ассетов, потом реализация.
3. Не менять остальные уроки заранее. Передать дизайнеру docs/DESIGNER-TABLE-CHIPS.md. После получения заменить рисунки и проверить расположение мест/фишек на 320/390.
4. Диапазоны с оценкой подключать только после проверки происхождения, формата, условий игры и прав на данные. Не выдумывать GTO, EV или частоты.
5. На реальном iPhone проверить установку, обновление без потери прогресса и офлайн. Браузерные проверки этого не заменяют.

Простой локальный проект для двух игроков: без сервера, аккаунтов, платежей и новой инфраструктуры. Прогресс сохраняем под прежним ключом river.progress.v1.
