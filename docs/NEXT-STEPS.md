# Следующие шаги PokChe

1. Пользователь проверяет опубликованные точечные правки урока 01. Остальные уроки пока не трогать без нового запроса.
2. В новом чате пользователь присылает отзыв по уроку 02 «Как идёт раздача». Читать HANDOFF.md и LESSON-02.md, сверить конкретные сцены, затем точечно исправить.
3. После приёмки урока 02 подготовить урок 03 «Позиции и стеки»: убрать повтор уже объяснённых позиций, последовательно разобрать стек, эффективный стек и SPR. Сначала записать структуру и примеры, определить недостающую графику, только затем реализовать. Это будущая работа, сейчас не выполнена.
4. Дальнейшие уроки наполнять по одному по тому же стандарту: понятия → наглядный пример → отдельная практика → разбор → повтор ошибок.
5. Диапазоны и матрицу-тренажёр подключать только после проверки конкретных префлоп-данных: происхождение, формат, число игроков, стеки, анте, рейк, размеры ставок, условия использования. Не приписывать GTO, EV и частоты, которых нет в источнике.
6. На реальном iPhone проверить установку, обновление PWA без потери прогресса, офлайн и жесты. Существующие автоматические тесты этого полностью не заменяют.

Ограничения: никаких параллельных переделок всей программы, сервера, аккаунтов, платежей, социальной части и упаковки в нативное приложение. Текущая цель — приятная и полезная ежедневная практика для двух человек.

Для нового чата можно отправить: «Продолжаем PokChe в этом проекте. Прочитай docs/HANDOFF.md и docs/NEXT-STEPS.md. Пока ничего не меняй: следующим сообщением пришлю замечания по уроку 02».
