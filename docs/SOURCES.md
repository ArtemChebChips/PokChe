## Кандидат: PokerCoaching Online 6-max

[Страница источника](https://pages.pokercoaching.com/100bb-charts) · [исходный PDF](https://poker-coaching.s3.amazonaws.com/tools/preflop-charts/online-6max-gto-charts.pdf).

| Поле | Результат проверки |
| --- | --- |
| Происхождение | PokerCoaching, авторская учебная переработка диапазонов |
| Формат | PDF с цветными матрицами, не машиночитаемая база |
| Игра | Онлайн-кэш, 6-max, 100 BB |
| Условие RFI | До игрока все сбросили; лимперы/рейзеры меняют ситуацию |
| Открытия | Повысить до 2,5 BB, с SB — до 3 BB |
| Блайнды | Размер SB отдельно в инструкции не подтверждён; BB — единица измерения |
| Анте | Не подтверждено |
| Рейк и cap | Не подтверждены |
| Частоты / EV | Исходные значения не приложены; чарты упрощены до чистых действий |
| Версия расчёта | Солвер, версия, дерево и точность не указаны |
| Права на перенос | Явное разрешение на встраивание и распространение не установлено |

Вывод: только ссылка для самостоятельного ознакомления. Данные не импортированы, точной GTO-стратегией не называются. Для подключения нужны условия рейка/анте и явное разрешение правообладателя. Стоимость разрешения не установлена, подписка не рассматривается как лицензия на перенос.

## Собственный постфлоп: b-inary/postflop-solver

[Репозиторий и README](https://github.com/b-inary/postflop-solver), [лицензия](https://github.com/b-inary/postflop-solver/blob/main/LICENSE), [пример basic.rs](https://github.com/b-inary/postflop-solver/blob/main/examples/basic.rs).

Библиотека Rust под AGPL-3.0. Разработка приостановлена автором; README предупреждает о несовместимых изменениях без смены версии. Это постфлоп-инструмент, не готовая префлоп-база. В первой версии код не встроен и расчёт не запускался: воспроизводимость конкретной базы пока не подтверждена. README содержит запуск `cargo run --release --example basic`. Пример задаёт диапазоны, доску, банк, стек, дерево ставок и порог exploitability.

Перед собственным набором следует:

1. Зафиксировать полный commit SHA, Rust toolchain, Cargo.lock и параметры сборки.
2. Сохранить точные комбинации диапазонов и веса, карты, банк, оставшиеся стеки, рейк, дерево размеров и разрешённые действия.
3. Сохранить seed, если используемый путь его требует, число итераций, достигнутую exploitability и единицы EV.
4. Повторить расчёт с теми же входами и проверить EV/частоты в пределах зафиксированного допуска; отдельно проверить карты и терминальные выплаты независимым оценщиком.
5. Сохранить исходный ввод, хеш дерева, вывод и журнал запуска. При любых изменениях условий рассчитать задачу заново.

Лицензия относится к использованию/изменению/распространению кода; нельзя объявлять результаты новой базы пригодными к распространению без проверки её происхождения и используемых входных данных. Никаких выводов об оптимальности в текущем приложении из этого исследования не следует.

## Проверка базовых ответов

Ответы по правилам и формулам генерирует собственное детерминированное ядро. Независимый оценщик `pokersolver` используется только в тестах. Эквити рассчитывается по всем возможным риверам против конкретной руки: победа даёт 1, ничья 0,5. Математическая погрешность симуляции отсутствует, отображение округляется. Эквити не выдаётся за оптимальное решение.
