# Урок 02 — Как идёт раздача

Цель: новичок понимает, откуда берётся банк, где сидит каждый игрок, какие карты открываются и какие действия разрешены. Формат примеров: шесть игроков, без анте; обязательные ставки 1 и 2 фишки. Короткая игра один на один имеет другой порядок и сюда не смешивается.

Три главы:
1. Начало: 6-max и метка дилера; обязательные ставки SB/BB; определение префлопа; по странице UTG, HJ, CO, BTN с подсветкой места; итоговая очередь.
2. Общие карты: флоп, тёрн, ривер на одной последовательной доске; определение постфлопа и смена первого игрока.
3. Решения: чек/бет; колл/рейз/фолд с суммами; олл-ин и завершение торгов; вскрытие или победа без вскрытия.

Визуал: схема стола с шестью подписанными местами (SVG), текущая позиция выделена; общая доска над личными картами, незаполненные места не выдаются за закрытые общие карты; Иваныч поясняет UTG и отличие «до» от «ещё». Всё делается из готовых карт, персонажа и средствами интерфейса. Дополнительный заказ дизайнеру не нужен.

Практика: первый ход и очередь до/после флопа, число открытых карт, определения действий, сумма для колла, рейз до суммы. Только проверяемые правила, без выдачи стратегического совета за единственно правильный ответ. Сохраняем идентификатор навыка order для совместимости прогресса.
