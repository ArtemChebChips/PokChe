# Экскурсия с Иванычем

Восемь ручных переходов: приветствие → уроки по порядку → свободный выбор темы → тренажёры → повтор ошибок → прогресс → настройки/офлайн → завершение с шуткой про масло. Используем фразы пользователя, без случайных вставок во время решения задач.

Первый запуск показывает экскурсию автоматически. Пропуск и завершение записывают отдельный ключ river.tour.v1; учебный прогресс не меняется. Повтор из настроек. Назад/далее, Escape, модальный фокус, отсутствие автоматического перелистывания. Иваныч меняет позу, сторону и положение; анимация появления только по переходу, отключается при prefers-reduced-motion.

Фон — реальные экраны приложения, соответствующий элемент выделяется. 320×568 и 390×844: текст, персонаж и кнопки доступны, никакого горизонтального скролла. Ассеты из существующего пакета; автомобиль пока не готов. Иконки 05–12 и бонуса из готового lesson-icons-v2 копируются в public/art без изменения оригиналов.
