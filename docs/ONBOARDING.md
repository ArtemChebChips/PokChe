# Экскурсия с Иванычем

Восемь ручных переходов: приветствие → уроки по порядку → свободный выбор темы → тренажёры → повтор ошибок → прогресс → настройки/офлайн → завершение с шуткой про масло. Используем фразы пользователя, без случайных вставок во время решения задач.

Первый запуск показывает экскурсию автоматически. Пропуск и завершение записывают отдельный ключ river.tour.v1; учебный прогресс не меняется. Повтор из настроек. Назад/далее, Escape, фокус внутри экскурсии, отсутствие автоматического перелистывания. Иваныч меняет позу, сторону и положение; анимация появления только по переходу, отключается при prefers-reduced-motion.

Экскурсия встроена отдельным блоком под реальным разделом, не накрывает его и не затемняет экран. Облако с хвостиком, персонаж увеличен вдвое; на коротких экранах общая вертикальная прокрутка. Соответствующий элемент выделяется. 320×568 и 390×844: текст, персонаж и кнопки доступны, никакого горизонтального скролла. Ассеты из существующего пакета; автомобиль пока не готов. Иконки 05–12 и бонуса из готового lesson-icons-v2 копируются в public/art без изменения оригиналов.

Правки текста: в интерфейсе «Пежо» по-русски, шутка про отыгрыш удалена, в экскурсии нет рассказа про копирование прогресса. Направленные позы запрошены в DESIGNER-TOUR-POSES.md; до готовности используются существующие.

В настройках есть отдельная кнопка следующего входа: river.tour.v1=pending. Перезагрузка или возвращение видимости приложения запускает приветствие; учебный прогресс и кэш сохраняются.

Исправление навигации: экскурсия находится внутри единственного прокручиваемого main. Шапка и нижние вкладки остаются на месте; порядок flex-элементов и высота всего приложения не меняются. Готовые point-up-left/right/down подключены, финал использует ivanych-oil из peugeot-v2. Поза назад не используется. Фраза «В отличие от моего Пежо» удалена.
