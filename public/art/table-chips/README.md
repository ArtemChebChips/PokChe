# Стол и фишки

Готовые PNG дизайнера из design/table-chips-v1/, скопированы без изменения пикселей. Исходники остаются в дизайнерской папке.

ChipArt.tsx использует contentBounds из qa.json как viewBox, чтобы прозрачные поля не уменьшали рисунок. Вид стопки условный; точная сумма всегда подписана. PokerTable размещает стол на общем поле 400×290, а места, карты, суммы и кнопку D отдельно.

Кнопка dealer-button.png заменена на dealer-button-relief.png: пользователь выбрал вариант с тонким объёмным бортиком. Размер и contentBounds сохранены; замена действует во всех сценах через общий ChipArt. Плоский вариант остаётся у дизайнера.
